# Dashboard มูลค่าการใช้ยาสมุนไพร สิทธิ UC

Dashboard ติดตามตัวชี้วัดมูลค่าการใช้ยาสมุนไพร (ED / NONED) ความถูกต้องของรหัสยา และยาจากแหล่งผลิต GMP
ข้อมูลจาก [MOPH Open Data](https://opendata.moph.go.th) ตาราง `s_ttm4` (OPD-อันดับการใช้ยาสมุนไพร)

## หน้ารายงาน

| หน้า | เนื้อหา |
|---|---|
| มูลค่ายาสมุนไพร สิทธิ UC (เลือกปีงบได้) | มูลค่า (ครั้ง × ราคาคอร์ส) เทียบเป้าหมาย 2,000 ล้านบาท (165 ล้านบาท/เขต) |
| ตรวจสอบความถูกต้องของรหัสยา | รหัสยา 24 หลักที่พบ / ถูกต้อง (มีในฐานรหัสยาของกรมการแพทย์แผนไทยฯ) |
| รายการรหัสยาที่ไม่ถูกต้อง | รหัสที่ไม่ถูกต้องที่พบใหม่ / หายไป ตามช่วงวันที่ (จาก snapshot รายวัน `history-<ปี>.js`) |
| ยา ED ที่ผลิตจากโรงงาน GMP | รหัสยา ED ที่มาจากแหล่งผลิตที่ได้รับ GMP หรือได้รับยกเว้น |
| ยา ED ที่มีการสั่งจ่าย | จำนวนรายการยา ED และหน่วยบริการที่มียา ED ≥ 10 รายการ |
| มูลค่ายาสมุนไพร ทุกสิทธิ | มูลค่า (vs_all × ราคาคอร์ส) |
| ED + NONED ทุกสิทธิ | มูลค่ายาในบัญชี (ED) และนอกบัญชี (NONED) |

## วิธีใช้

ต้องมี [Node.js](https://nodejs.org) 18 ขึ้นไป

```bash
# 1) ดาวน์โหลดข้อมูลดิบจาก API (ประมาณ 25–30 นาที เพราะ API จำกัดอัตราการเรียก)
node scripts/fetch-data.mjs            # ค่าเริ่มต้น = ปีงบปัจจุบันและปีก่อนหน้า

# 2) สร้างไฟล์ข้อมูลให้ dashboard (data-<ปี>.js)
node scripts/build-data.mjs

# 2.1) บันทึก snapshot รหัสยาที่ไม่ถูกต้องของวันนี้ (history-<ปี>.js)
node scripts/track-invalid.mjs

# 3) เปิด dashboard ที่ http://localhost:8080
node scripts/serve.mjs
```

ถ้าได้ไฟล์ Excel "106 รายการ-KPI มูลค่ายา" ฉบับใหม่ ให้สร้างตารางแปลงรหัส (`lookups/`) ใหม่ก่อนขั้นที่ 2

```bash
npm install
npm run lookups -- "path/to/106 รายการ-KPI มูลค่ายา_ตรวจราชการ.xlsb"
```

## โครงสร้าง

```
index.html               dashboard (ไฟล์เดียว ไม่ต้อง build)
data-2569.js, -2568.js   ข้อมูลสรุปที่ dashboard ใช้
lookups/                 ตารางแปลงรหัสยา / ผู้ผลิต / หน่วยบริการ
scripts/fetch-data.mjs   ดาวน์โหลดข้อมูลดิบจาก API -> cache/
scripts/build-data.mjs   คำนวณตามเกณฑ์ KPI -> data-<ปี>.js
scripts/build-lookups.mjs  สร้าง lookups/ จากไฟล์ Excel ของกรมการแพทย์แผนไทยฯ
scripts/serve.mjs        เซิร์ฟเวอร์สำหรับเปิดดูในเครื่อง
```

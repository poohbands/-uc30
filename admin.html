GitHub token

ใช้บันทึกการตั้งค่าลงไฟล์ config.json ใน repo · เก็บไว้ในเบราว์เซอร์นี้เท่านั้น

วิธีสร้าง token
  1. เปิด GitHub → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → เลือก REPO
  3. Permissions → Repository → Contents: Read and write
  4. กด Generate แล้วคัดลอก token มาวางในช่องด้านบน
